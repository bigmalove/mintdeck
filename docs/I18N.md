# 多语言（i18n）

界面支持 **简体中文（源语言）、繁体中文、English、日本語**，默认跟随系统语言，也可以在
`系统设置 → 小程序 → MintDeck → 外观 → 界面语言` 里单独指定。

```
简体中文 zh_CN   ← msgid 本身（源码里的中文就是词典键）
繁體中文 zh_TW   po/zh_TW.po
English   en     po/en.po
日本語     ja     po/ja.po
```

## 两条渲染路径，一份 po

Cinnamon 的界面分两种画法，翻译因此走两条路，但**文案只有一份来源**：`po/*.po`。

| 路径 | 谁在画 | 翻译怎么生效 |
| --- | --- | --- |
| 悬浮岛 / 展开面板 / 右键菜单 | 本 applet 自己的 JS（St + cairo + Pango 自绘） | `lib/core/i18n.js` 查 `lib/core/i18nData.js` 里的词典，**切语言立即生效**，不用重启 shell |
| 设置窗口、小程序列表里的名字与简介 | `xlet-settings`（Python）与 Cinnamon 自己 | gettext 的 `.mo`，domain 就是 uuid `mintdeck@bigmalove`（见 `/usr/share/cinnamon/js/ui/appletManager.js:617`） |

`tools/i18n-build.py` 从同一批 po 生成这两样东西：

```
po/*.po ──┬─→ mintdeck@bigmalove/lib/core/i18nData.js                     （画布文字，随设置切换）
          └─→ po/build/<locale>/LC_MESSAGES/mintdeck@bigmalove.mo         （gettext，装到 ~/.local/share/locale）
```

`.mo` 由 `tools/install.sh` 拷到 `~/.local/share/locale/<locale>/LC_MESSAGES/mintdeck@bigmalove.mo`。
没有 `msgfmt` 时安装脚本会跳过这一步：悬浮岛照样能切语言，只是设置窗口保持中文。

## 写文案的规则

1. **msgid 就是简体中文原文**，不另造 key 表：

   ```js
   const _ = I18n.t;
   this._text(cr, _('未检测到播放器'), ...);
   ```

2. **占位符用 `%s` / `%d`**，参数按顺序代入。译者可以调换占位符在句子里的位置，但不能调换参数语义：

   ```js
   _('%s 个会话 · 累计 %s 积分', sessions, credits)   // 第一个 %s 永远是会话数
   ```

3. **复数用 `I18n.tn()`**，双语 msgid 都写中文（po 里生成 `msgid_plural`）：

   ```js
   tn('%s 天前', '%s 天前', days)
   // en.po: msgstr[0] "%s day ago" / msgstr[1] "%s days ago"
   // ja / zh_TW 的 nplurals=1，只有 msgstr[0]
   ```

4. **不要拿译文做逻辑判断**。状态一律用状态码，让 UI 只负责显示：

   ```js
   // 以前：if (c.statusText.indexOf('读取失败') >= 0)   ← 换语言就失效
   // 现在：if (c.statusCode === 'error')
   ```

   同理，播放态是布尔值 `playing`（来自 MPRIS 的 `Playing`），不是「播放中」这个字符串。

5. **不要新建顶层已翻译常量**。`imports` 在 applet 构造前就执行完，那时 locale 还没定，
   顶层 `const PAGE_TITLES = { usage: _('AI 用量') }` 会把中文冻结在加载那一刻；用函数（`pageTitle(id)`）在画的时候取。

## 加一条文案

```bash
# 1. 代码里写 _(...) / tn(...)
vim mintdeck@bigmalove/lib/deck/panel.js

# 2. 抽 msgid → pot，并把新条目并进各语言 po（旧译文保留）
tools/i18n.sh update

# 3. 填 msgstr；msgfmt 自检
msgfmt -c -o /tmp/x.mo po/en.po

# 4. 生成 i18nData.js 与 .mo
tools/i18n.sh build

# 5. 测试会拦住漏译与占位符不一致
node --test tests/i18n.test.js
```

`tests/i18n.test.js` 的守卫：每条 msgid 在 en / zh_TW / ja 都必须有译文、占位符数量一致、
「译文等于原文」视为漏译（品牌名与语言自称除外）、`i18nData.js` 与 po 必须同步、
deck 层与 `applet.js` 里不允许出现没包 `_()` 的中文字符串。

## 加一门语言

1. 在 `tools/i18n-build.py` 的 `LOCALES` 里加一项（含 `Plural-Forms`）；
2. `lib/core/i18n.js` 的 `KNOWN_LOCALES` 加语言码；
3. `settings-schema.json` 的 `language.options` 加选项（标签用该语言自己的写法）；
4. `tests/i18n.test.js` 的 `TRANSLATED_LOCALES` 加语言码（不加就不会被漏译测试守住）；
5. `tools/i18n.sh init` 生成 po 骨架 → 翻译 → `tools/i18n.sh build`。

## 画布布局也要照顾译文

自绘界面里没有「自适应布局」，所以凡是**按中文固定尺寸**的地方都要改成按译文实测：

- 面板底部的 `Today / 7 days` 标签列宽原先写死 `12 × 2.7`（两个汉字），英文会压住数字，
  现在用 `Pango` 实测标签宽度再取最大值（`panel.js` 的 `captionW`）。
- 收起态的宽度估算按字符类型给权重（中文 11px / 西文 6.6px，`island.js:estimateText`），
  这是估算而非排版，长英文标题会被 `textCap` 截断——这是「自动宽度」的既定取舍。

改完 `lib/core/i18n.js`、`i18nData.js` 这类被 `imports` 缓存的模块后，`tools/dev-reload.sh`
只重载 xlet，模块还是旧的：要么 `Alt+F2 → r`，要么在终端里

```bash
gdbus call --session --dest org.Cinnamon --object-path /org/Cinnamon \
  --method org.Cinnamon.Eval 'imports.ui.main.restartCinnamon(false)'
```

重起 shell 才看得到效果（悬浮岛/面板会闪一下，已开的窗口不受影响）。

## 已知取舍

- **设置窗口的语言不跟随上面的选择**：`xlet-settings` 是独立进程，gettext 在进程启动时绑定语言，
  所以设置窗口永远跟随系统 locale。悬浮岛与面板则是即时切换的。
- **译文回退顺序**：选定语言 → 基语言（`de_AT` → `de`）→ 简体中文。任何一层缺失都直接显示中文原文，
  不会出现空串。
- **字体**：`Noto Sans` 在中日文环境下由 fontconfig 回退到本机 CJK 字体；没有做逐语言的字体栈。
